# Тревожная кнопка для физкультуры

Веб-приложение для студентов: если на занятии стало плохо, студент нажимает большую красную кнопку **SOS** — и преподавателю уходит SMS с именем студента, группой и ссылкой на Яндекс.Карты с точкой, где он находится.

- **Преподавателю ничего не нужно устанавливать** — тревога приходит обычной SMS.
- **Студенту ничего не нужно устанавливать** — достаточно открыть ссылку или отсканировать QR-код. Работает на iPhone и Android.
- **Работает без интернета** — после первого открытия страница хранится на телефоне, а GPS и SMS интернет не нужен.
- **Нет сервера и базы данных** — данные никуда не уходят, кроме самой SMS.

## Как пользоваться

**Преподаватель** открывает страницу настройки `setup.html`, вводит свой номер телефона (и по желанию имя и группу) — и получает ссылку и QR-код для студентов. QR-код можно распечатать и повесить в спортзале.

**Студент** открывает ссылку, один раз вводит фамилию и имя и разрешает доступ к геолокации. Дальше — одна кнопка:

1. Нажал **SOS** → телефон определяет местоположение.
2. Открывается приложение «Сообщения» с готовым текстом на номер преподавателя.
3. Студент нажимает «Отправить».

Пример SMS:

> SOS! Иванов Иван, ИВТ-21: мне плохо, нужна помощь. Я здесь: https://yandex.ru/maps/?pt=37.617635,55.755814&z=18&l=map (точность ±15 м)

Ещё на экране есть кнопки «Позвонить преподавателю» и «Позвонить 112», короткая памятка «Пока ждёшь помощь» и кнопка «Проверить, что всё работает» — она отправляет тестовую SMS.

## Как опубликовать (бесплатно, GitHub Pages)

1. В репозитории: **Settings → Pages → Source: GitHub Actions**.
2. Готовый сценарий `.github/workflows/pages.yml` сам публикует сайт после каждого изменения (ход публикации — во вкладке **Actions**).
3. Сайт доступен по адресу вида `https://<имя>.github.io/Fizra/`, а страница настройки — `https://<имя>.github.io/Fizra/setup.html`.

GitHub Pages сразу даёт HTTPS — без него браузер не разрешает геолокацию.

## Как это устроено (для защиты)

| Файл | Что делает |
|---|---|
| `index.html`, `app.js` | Кнопка для студента: имя, геолокация, текст SMS, открытие «Сообщений» |
| `setup.html`, `setup.js` | Страница преподавателя: собирает ссылку `?p=телефон&g=группа&n=имя` и рисует QR-код |
| `phone.js` | Приводит номер к виду `+79991234567`, как бы его ни ввели |
| `sw.js` | Сервис-воркер: хранит копию страницы на телефоне, чтобы она открывалась без интернета |
| `manifest.webmanifest`, `icons/` | Чтобы кнопку можно было добавить на экран телефона как приложение |
| `vendor/qrcode.js` | Готовая библиотека для QR-кодов (Kazuhiko Arase, MIT) |

Использованные возможности браузера:

- **Geolocation API** — координаты телефона (GPS, Wi-Fi, сотовые вышки).
- **Ссылка `sms:`** — открывает приложение «Сообщения» с готовым текстом. iPhone ждёт текст после `&body=`, Android — после `?body=`, поэтому формат выбирается по системе.
- **Service Worker** — офлайн-режим.
- **localStorage** — запоминает имя студента и настройки группы.

Координаты определяются заранее, пока открыт главный экран, поэтому при нажатии SOS сообщение открывается сразу, без ожидания GPS. Если геолокацию не разрешили или нет сигнала, SMS всё равно уходит — просто без точки на карте.

В манифесте специально нет `start_url`: тогда кнопка, добавленная на экран телефона, открывается по той же ссылке, что и была открыта, — вместе с номером преподавателя.

## Ограничения

- Браузер не может отправить SMS сам (это защита от спама), поэтому последнее нажатие «Отправить» делает студент.
- В помещении GPS неточный — точность (±метры) указывается в SMS.
- Номер преподавателя виден в ссылке — её стоит давать только своей группе.
- Это учебный проект, он не заменяет звонок в 112.
