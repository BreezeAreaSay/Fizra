# Тревожная кнопка 2.0 — с панелью преподавателя

**Как поставить на свой сервер — [selfhost/README.md](selfhost/README.md).** Там всё уже собрано: нужен только Node.js и ваш nginx/Caddy.

Копия на хостинге AppDeploy: https://app-ybcd9c.v2.appdeploy.ai/ (из России открывается только через VPN).

Что умеет:

- **Студент** сканирует QR-код, один раз вводит фамилию, имя и телефон — и попадает в список группы. Если станет плохо, нажимает **SOS**.
- **Преподаватель** открывает свою панель по ссылке: видит список студентов с телефонами (по нажатию — звонок) и тревоги в реальном времени — с сиреной, системным уведомлением, картой и кнопками «Принял, иду» / «Закрыть тревогу».
- **SMS остаётся вторым каналом**: после нажатия SOS на телефоне студента сразу открывается SMS преподавателю с точкой на Яндекс.Картах. Если интернета нет, SMS — основной канал.
- Студент видит, что преподаватель принял тревогу («Преподаватель увидел тревогу и идёт к тебе»), может отменить её («всё в порядке») или проверить связь кнопкой «Проверить, что всё работает».

## Как пользоваться

1. Преподаватель на главной странице нажимает **«Создать группу»**, вводит название и свой телефон.
2. Открывается панель. **Ссылку на панель нужно сохранить** — по ней открываются список и тревоги (она секретная, студентам её не показывать).
3. На панели есть QR-код — его можно распечатать (кнопка «Распечатать») и повесить в зале или отправить ссылку в чат группы.
4. Во время занятия на панели нажать **«Включить звук и уведомления»** и держать страницу открытой.

## Как устроено (для защиты)

```
Телефон студента ──SOS──▶ сервер (AppDeploy) ──WebSocket──▶ панель преподавателя
        │                     база данных:                    (сирена, карта,
        │                     группы, студенты, тревоги        список студентов)
        └──────SMS с координатами──────────────────────────▶ телефон преподавателя
```

| Файл | Что делает |
|---|---|
| `src/app/router.ts` | Один HTML-файл, экраны переключаются по адресу: `#/s/КОД` — студент, `#/t/КОД/КЛЮЧ` — преподаватель, `#/new` — новая группа |
| `src/app/student.ts` | Регистрация, кнопка SOS, статус тревоги, SMS |
| `src/app/teacher.ts` | Панель: тревоги, список студентов, журнал, QR-код |
| `src/app/geo.ts` | Геолокация (определяется заранее, чтобы при нажатии не ждать GPS) |
| `src/app/alarm.ts` | Сирена (Web Audio), системные уведомления, вибрация, экран без затухания |
| `src/app/realtime.ts` | Живые обновления по WebSocket |
| `src/app/backend.ts` | Запросы к серверу |
| `backend/routes.ts` | Сервер: группы, студенты, тревоги, проверка доступа |
| `public/sw.js` | Service worker: кнопка открывается без интернета, уведомления на Android |

Безопасность:

- Панель открывается только по секретному ключу из ссылки преподавателя; без ключа нельзя ни прочитать список, ни подписаться на тревоги.
- Студент подтверждает себя токеном, который получил при регистрации: чужую тревогу отменить нельзя.
- Телефоны студентов видит только преподаватель.

## Два способа запуска из одних исходников

- **Свой сервер** (`server/`, готовая сборка в `selfhost/`): `server/sdk.ts` — база в JSON-файле и WebSocket, `server/client.ts` — запросы из браузера, `server/main.ts` — HTTP-сервер. Сборка: `npm install && npm run selfhost:build`.
- **AppDeploy**: платформа сама подставляет `@appdeploy/sdk` и `@appdeploy/client`.

Проверить локально:

```bash
npm install
npm run selfhost:build
cd selfhost && PORT=3077 DATA_DIR=./data node server.mjs   # http://localhost:3077/
```
